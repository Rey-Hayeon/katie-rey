## 규칙

- **글 문서는 노션, 이미지 원본은 이 폴더.** 기획안, 견적, 문의 기록, 관심 신청 폼처럼 휴대폰에서 볼 문서는 노션 [꼬물상점 표](https://app.notion.com/p/40dfdffd4437803ba434fa7c7697198f)에 새 페이지로 쓴다. 노션 페이지에는 대표 시안 몇 장만 올린다 (2026-11-25).
- 꼬물상점의 기준(대상, 상품 방향, 30명 기준, 비용 상한)은 노션이 아니라 [docs/ssot/kkomul-store.md](../docs/ssot/kkomul-store.md)에서만 고친다.

- 검수 전 새 이미지는 `MASTER`로 이름 짓지 않는다 (인수인계 README 규칙).
- 관심 신청자 이름·연락처는 여기에 두지 않는다. 신청 수만 기록한다.
