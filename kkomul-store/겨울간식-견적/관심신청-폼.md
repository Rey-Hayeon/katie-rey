# 관심 신청 폼 (구글 폼)

> 겨울 간식 세트 수요 조사 폼. 응답자 이메일·이름은 이 저장소에 남기지 않는다. 신청 수만 적는다.

## 상태 [사실]

- Claude가 데스크톱 앱 브라우저로 만들었다. Katie 구글 계정, 이름 '꼬물상점 겨울 간식 세트 관심 신청 (EN)'.
- 수정 화면: https://docs.google.com/forms/d/1wZ9bRnBAyzDPUsFhGJg4jJ4-WRyP8V2LwMVnEfWOx8U/edit
- **게시 전 초안.** 링크를 받은 사람도 아직 열 수 없다.
- 예상 가격이 ₩30,000으로 들어가 있다. 견적 기준으로는 원가보다 낮아서 바꿔야 한다 ([README.md](README.md)).

## 내용

- 제목과 소개 글: 세트 구성, 예상 가격, "예시 시안이에요", "주문이 아니에요" 안내. 영어.

| 질문 | 형식 | 필수 |
| --- | --- | --- |
| Q1. 3만 원이면 살 건지 ("Yes, definitely!" 등) | 객관식 | 필수 |
| Q2. 가장 마음에 드는 품목 | 객관식 | 필수 |
| Q3. 낱개로도 살 품목 | 체크박스 | 선택 |
| Q4. 군고구마 디자인 (통째 / 반 가른 모양) | 객관식 | 필수 |
| Q5. 받는 방법 | 객관식 | 필수 |
| Q6. 사는 나라 | 단답형 | 선택 |
| Q7. 이메일 | 단답형 | 필수 |
| Q8. 이메일 사용 동의 | 체크박스 | 필수 |
| Q9. 하고 싶은 말 | 장문형 | 선택 |

- 설정: 이메일 자동 수집 끔. 응답 1회 제한 끔 (구글 계정 없이 답할 수 있게).
- 판단 기준: Q1 "Yes, definitely!" 수. [초안] 관심 30명이 구매 30명은 아니라서 기준을 40~50명으로 높이거나 질문을 나눠 보는 방법도 있다.
