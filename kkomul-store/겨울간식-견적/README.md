## 업체 견적 [사실]

### 모형1번지 (A업체) · https://www.make59.com/

| 품목 | 30개 기준 개당 | 15개 기준 개당 |
| --- | --- | --- |
| 붕어빵 키링 | 8,000원 | 12,000원 |
| 호떡 그립톡 | 7,000원 | 11,000원 |
| 군고구마(통째) 젓가락 받침 | 10,000원 | 14,000원 |
| 군고구마(반 가른 형태) 젓가락 받침 | 14,000원 | 18,000원 |

처음 한 번 드는 비용 (샘플 제작 시, 첫 견적서 이미지):

| 항목 | 금액 | 무엇 |
| --- | --- | --- |
| 조각비 | 400,000원 | 원본 모양을 손으로 깎는 비용 |
| 몰드비 | 50,000원 | 원본으로 실리콘 틀을 뜨는 비용 |
| 샘플비 | 150,000원 | 틀로 샘플을 1개씩 만드는 비용 (고구마 2종 포함 4개 기준) |
| 합계 | 600,000원 | **VAT 별도** |

- 3D 파일이나 원하는 크기의 실물을 보내면 조각비 400,000원이 빠진다 (견적서). 실물로 되는지는 확인 중.
- 계약금 50% 입금 뒤 제작. 납기가 긴 편.
- 실물 보내는 법 (견적서 주의사항): 꽝꽝 얼리기, 평평하게 눕히기(세우거나 쌓지 않기), 흠집 주의(틀에 그대로 찍힘), 여러 개 중 가장 예쁜 것 고르기.

### 푸드스타일 (돈잇, 푸드스타일모형) · https://donteat.co.kr/

| 품목 | 개당 |
| --- | --- |
| 붕어빵 | 17,000원 |
| 호떡 | 12,000원 |
| 고구마 | 12,000원 |
| 몰드비 | 50,000원~ |

- 원하는 크기를 정확히 맞출 수는 없다. AI 그림과 음식 모형은 전혀 다른 디자인으로 나올 수 있다.
- 키링용으로 많이 만들었다. 물리적인 힘을 주지 않으면 쉽게 부서지거나 색이 벗겨지지 않는다.
- 키링과 톡을 붙여서 출고할 수 있다. 샘플도 되며, 샘플 비용은 협의.
- 어린이집 납품 재질. 식품에 닿아도 되지만 처음에 코팅 냄새가 난다.
- 딱딱해서 젓가락 받침으로는 추천하지 않는다.

## 비용 계산 (모형1번지 기준) [계산]

가정: 고구마는 통째 1종. '실물 보냄'은 조각비가 빠진다고 가정한 것이고, 아직 업체가 확인해 주지 않았다.

| | 15세트 | 30세트 |
| --- | --- | --- |
| 세트당 단가 | 37,000원 | 25,000원 |
| 제품비 | 555,000원 | 750,000원 |
| 처음 비용 (실물 보냄) | 200,000원 | 200,000원 |
| 합계 (VAT 별도) | 755,000원 | 950,000원 |
| 합계 (VAT 10% 포함) | 830,500원 | 1,045,000원 |
| 세트 1개당 원가 (VAT 포함) | 약 55,400원 | 약 34,800원 |
| 조각비까지 내면 합계 (VAT 포함) | 1,270,500원 | 1,485,000원 |

- 50만 원 예산은 어느 경우에도 넘는다. 가장 싼 경우(30세트, 실물 보냄)도 약 2배.
- 30세트는 15세트보다 약 21만 원 더 내고 15세트를 더 받는다.
- 15세트는 45,000원에 다 팔아도 적자 (−155,500원, 포장비 세트당 약 1,000원 포함).
- VAT: '별도'라고 적힌 건 샘플 비용 줄뿐이다. 개당 단가도 별도라고 [초안]으로 보고 계산했다. 단가에 VAT가 포함이면 30세트 합계는 970,000원.
- 15세트 단가가 오기 전 계산(30개 단가로 15세트, 약 57.5만 원)은 맞지 않게 됐다.
