# Daily Hangul (한국어 학습 앱)

> 상태: **검토 중, 질문 답장 초안** (2026-11-25)
> 연락: 인스타 DM. 앱 창업자가 직접 연락.

## 조건 (제안)

- 유료 협업. 영상 5개를 **내 계정**에 올린다.
- 훅과 소재는 앱 쪽이 주고, 영상은 내 스타일로.
- 기본료 영상 1개에 $20 + 조회수 보너스.
- 이메일 주소를 달라고 함.

## Claude 의견 [초안]

- 팔로워 대부분이 한국에 관심 있는 영어권이라 앱과 오디언스는 잘 맞는다.
- 5개를 내 계정에, 기본료 개당 $20은 낮다.
- 브랜드가 준 훅을 그대로 써야 하면 SSOT의 '콘텐츠 자율권' 기준과 부딪힌다.
- 답장 두 가지를 만들었다: 질문만 / 질문 + 기본료를 개당 $70쯤으로 올려 달라는 요청. 못 올린다면 영상 수를 2~3개로 줄이자고 제안.

## 물어볼 것 (답장 초안)

1. 5개 모두 내 인스타에 올리는지 (틱톡은 안 함)
2. 훅을 꼭 써야 하는지, 내 스타일로 바꿀 수 있는지
3. 보너스 조회수 기준: 영상별인지, 게시 후 며칠인지, 구간이 누적되는지
4. 유료 광고·파트너십 광고로 쓰는지, 쓴다면 얼마 동안
5. 일정
6. 지급 방법·시점 (PayPal, Wise 등)
