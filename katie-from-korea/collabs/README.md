## 정리 규칙

- 협업 제안이 오면 한 줄 추가: 협업처, 무엇, 받는 것, 상태.
- 상태: 제안 받음 → 검토 중 → 수락 → 촬영 → 게시 → 완료 (돈·제품 받음) / 거절 / 답 없음.
- 조건이 여러 개거나 일정이 있으면 `협업처.md` 파일을 따로 만든다.
- 담당자 이름·연락처·주소, 계약서 원본은 여기에 남기지 않는다.
- 협업 콘텐츠는 이해관계를 밝힌다 (유료 파트너십 표시).
